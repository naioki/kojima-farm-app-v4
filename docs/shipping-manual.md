# 出荷・配送作業マニュアル（積み込み／荷降ろし）

小島農園の出荷作業者・配送担当者向けの手引きです。
はじめての人が1人で回せるところまでを目標に、順番どおりに書いています。

対象は「荷捌き場での積み込み」から「各店舗での荷降ろし」「帰着後の後片付け」まで。
システム（チェックリスト画面）の使い方も途中に挟んであります。

> 開発・デプロイの話は README と `docs/DEPLOY.md` にあります。この文書は現場用です。

---

## 0. この作業のいちばん大事な原則

3つだけ覚えてください。あとは全部この派生です。

1. **先に積んだものは、最後に降りる。**
   荷物の出し入れは**後ろの入り口から**行います（脇のウィングは上げません）。
   片側からしか出し入れできないので、前方（運転席側）に積んだ荷物は、
   手前の荷物を全部降ろすまで取り出せません。だから
   **最後に配達する店を、いちばん先に積んで運転席側に置きます。**
   **積む順と降ろす順は必ず逆**になります。
   → 詳細は「2. 積み込みの順番（LIFO）」

2. **数えるのは「箱（コンテナ）」の数。**
   数量（個数）ではありません。伝票に「120」と書いてあっても、
   現場で数えるのは「10入り × 12箱」の **12** です。
   → 詳細は「1-3. 箱の数え方と端数箱」

3. **端数箱は、店舗をまたいで足さない。**
   A店の端数3個とB店の端数5個は「8個入り1箱」ではありません。
   **別々の箱が2つ**あります。ここを間違えると、必ず積み残しか積み過ぎになります。

## 1. 出発前の準備

### 1-1. 服装・持ち物

- **服装**: 動きやすい長袖・長ズボン、安全靴（つま先が保護されたもの）、
  作業用手袋。夏でも半袖・サンダルは不可。コンテナの角と縁で手足を切ります。
- **必携**:
  - スマートフォン（チェックリスト用。**充電済み**＋車載充電ケーブル）
  - 紙の一覧表・ラベル（システムから印刷したもの）
  - 筆記具（油性ペン＋ボールペン）
  - 免許証
  - 台車（店舗によって必要）
- **あると助かる**: 予備の輪ゴム／養生テープ、雨具、軍手の替え、
  検品用の小さいメモ帳。

### 1-2. 帳票を先に用意する

積み始める前に、**紙とスマホの両方**を手元に用意します。

| もの | 何に使うか |
|---|---|
| 一覧表（PDF） | 全体の総数確認、店舗ごとの内容確認 |
| ラベル（PDF） | コンテナの差し札に差す（後述） |
| チェックリスト画面 | 進捗の共有。今どこまで積んだか／降ろしたか |

紙は今まで通りメインで使ってください。
スマホのチェックリストは紙の**置き換えではなく**、
「2人で作業したときにお互いの進み具合が見える」ためのものです。

### 1-3. 箱の数え方と端数箱

一覧表の1行はこう読みます。

```
青葉台  トマト  L  10入り  12箱 + 端数6
```

- **通常箱** = 12箱（各10入り）
- **端数箱** = 6個入りの箱が **1箱**
- **運ぶコンテナの数** = 12 + 1 = **13箱**

端数が0のときは端数箱はありません。
アプリの表示もこれに合わせています。

| アプリの表示 | 意味 |
|---|---|
| `13箱（うち端数1箱・6）` | 全部で13箱。うち1箱は6個しか入っていない |
| `端数1箱（6）` | 6個入りの箱が1箱だけ |
| `12箱` | 満量の箱が12箱。端数なし |

**繰り返しますが、端数箱は店舗ごとに独立した箱です。**
品目ごとの合計を見て「端数2箱」と出ていたら、それは
「中身が半端な箱が2つある」という意味で、
中身を足して1箱にまとめることはできません（別の店に行く荷物なので）。

### 1-4. 総数を先に数える（過不足チェック）

**積み始める前に、必ず全体の総数を数えます。** これを飛ばすと、
最後の店で足りないことに気づいて全部積み直すことになります。

手順:

1. 一覧表の一番下（または画面ヘッダー）の **全体の箱数** を確認する。
   - チェックリスト画面のヘッダーに `全 N 軒 / M 箱` と出ています。この **M** です。
2. 荷捌き場に出ている荷物を、品目ごとにざっと数える。
   - 品目ごとに「満量の箱が何箱」「端数の箱が何箱」を数える。
   - チェックリスト画面の「積み込み」タブを下にスクロールすると
     **「品目ごとの合計（積む前の総数確認）」** があります。ここを開くと
     品目・規格ごとの箱数と、その品目が行く店舗名が出るので、
     これと突き合わせると早いです。
3. 合計が **M** と合うか確認する。

**合わないときは、積み始めないでください。** 先に原因を潰します。

| 症状 | まず疑うこと |
|---|---|
| 足りない | 冷蔵庫・別のパレットに残っていないか。まだ上がってきていないか |
| 多い | 前日の残り、別便の荷物が混ざっていないか |
| 品目が合わない | 規格違い（L と 2L など）の取り違え。ラベルを見て確認 |

自分で解決できない差異は、**積む前に**責任者へ連絡します。
「たぶん大丈夫」で出発するのが一番損害が大きいです。

### 1-5. ラベルを差し札に差す

コンテナには差し札（札差し）があります。**ここにラベルを差します。**

- ラベルは**店舗名が外側から読める向き**に差す。
  降ろすときに札を引っ張り出して確認するのでは遅いです。
  通路側・扉側から立ったまま読める向きに揃えます。
- 段積みしたとき、**上の箱で札が隠れないように**差す位置を揃える。
- 端数箱には特に確実に差す。端数箱は見た目が同じで中身が違うので、
  札がないと後で判別できません。
- 札が抜けやすいコンテナは、養生テープで軽く留める（剥がせる程度に）。

**ラベルの差し忘れは、荷降ろしのときに全箱を開けて確認する作業に化けます。**
ここは急がず確実にやってください。

### 1-6. 荷捌き場でのパレットの並べ方

積み込みを始める前に、**取り出す順に荷物を並べ替えておく**と作業が半分になります。

- **先に積む店舗の荷物を、通路の手前（取りやすい位置）に出す。**
- **後で積む店舗の荷物は、奥やフォークリフトの爪を差す面の側に置く。**
  フォークで差す面を後回しの荷物で塞いでも困りません。逆に、
  先に積みたい荷物をフォークの差し面の向こうに置くと、
  その1箱を出すためにパレットごと動かすことになります。
- パレットを動かす前に**周囲に人がいないか声を出して確認**。
  フォークリフト作業中は歩行者側が絶対に優先です。

## 2. 積み込みの順番（LIFO）

### 2-1. 基本

**荷物は後ろの入り口から出し入れします。**（脇のウィングは上げません）
片側からしか出し入れできないので、順番が決まります。

**積む順 = 一覧表・チェックリストの「積み込み」タブに出ている順。
トラックの前（運転席側）から詰めていきます。**

先頭の店舗（習志野台）が**最初**に積まれ、トラックの**いちばん前**に入ります。
つまり**最後に配達する店を、いちばん先に積んで運転席側に置く**ことになります。

そして、

**降ろす順 = 積んだ順の逆。** 後ろの扉を開けて手前にあるもの、
つまり**最後に積んだ店舗が最初に降ります**。
最初に積んだ習志野台は**最後**に降ります。

これが LIFO（Last In, First Out / 後入れ先出し）です。
アプリの「荷降ろし」タブは、この降ろす順にそのまま並んでいます。
**自分で順番を計算する必要はありません。タブを切り替えるだけです。**

```
        トラック前方（運転席側）                     後方（扉）＝出し入れ口
        ┌──────────┬──────────┬──────────┬──────────┐
積む→   │ 1番目に  │ 2番目に  │ 3番目に  │ 4番目に  │
        │ 積む店   │ 積む店   │ 積む店   │ 積む店   │
        └──────────┴──────────┴──────────┴──────────┘
                                                    ←降ろす
        （最後に降りる＝     　　　　　　　（最初に降りる＝
          最後に配達する店）                最初に配達する店）
```

### 2-2. なぜ順番を守るのか

順番を崩すと、店の前で「奥の荷物を出すために手前の荷物を一度全部おろす」
ことになります。路上・店舗の搬入口でそれをやると、

- 時間が倍以上かかる（後続の店舗の時間指定に響く）
- 荷物を地面に置くことになり、汚損・破損のリスクが上がる
- 通路や車道を塞ぐ

**1軒ぶんの積み間違いが、その日の全行程に影響します。**
順番だけは、急いでいても絶対に守ってください。

### 2-3. 店舗ごとに数えながら積む

**店舗単位で区切って、数えながら積みます。** 全部まとめて積んでから
数えるのは不可。どこで狂ったか分からなくなります。

1店舗ぶんの手順:

1. チェックリスト画面で**今の店舗**を確認する（画面上部に大きく出ています）。
2. その店舗の荷物を全部集める。
3. **品目ごとに箱を数える。** 画面の各行に `13箱（うち端数1箱・6）` のように
   出ているので、それと突き合わせる。
4. 合っていたら積む。積みながら（または積み終わってから）**画面の行をタップして
   チェック**を入れる。
5. その店舗の全行がチェックできたら、**「次の店舗へ」**を押す。
6. 次の店舗へ。

**1店舗ぶんが合わない時点で止めて確認します。**
先に進むと、原因の切り分けができなくなります。

### 2-4. 積み付け（荷崩れさせない置き方）

順番が正しくても、崩れたら意味がありません。

- **重いものは下、軽いものは上。** 例外なし。
- **段積みは、下の箱の縁にきちんと載せる。** 半分ずらして載せると崩れます。
- **同じ店舗の荷物は縦に固める。** 縦1列＝1店舗にすると、
  降ろすときに横に散らばった箱を探さなくて済みます。
- **段積みの上限を守る。** つぶれる品目（葉物・トマトなど）は
  積み上げすぎない。下の箱がへこんだら1段減らす。
- **左右の重量を偏らせない。** 片側に寄せると走行が不安定になります。
- **隙間を作らない。** 隙間があると走行中に荷物が動いて崩れます。
  詰められないときは、空コンテナや緩衝材で埋める。
- **扉際の荷物は特にしっかり固定する。** 扉を開けた瞬間に落ちるのが
  いちばん多い事故です。開ける前に一呼吸置いて、体を扉の正面から外す。

### 2-5. 積み終わったら（出発前の最終確認）

出発前に、これだけ確認します。

- [ ] チェックリスト画面の「積み込み」タブが**残り店舗 0** になっている
- [ ] 荷捌き場に**荷物が残っていない**（残っていたら積み忘れ）
- [ ] 紙の一覧表の総数と、実際に積んだ箱数が合っている
- [ ] 荷物が動かないか、手で押して確認した
- [ ] 扉・あおりが確実に閉まっている（ロックまで）
- [ ] 紙の一覧表・ラベルの控えを車内に持った
- [ ] 台車を積んだ
- [ ] 冷蔵・保冷が必要な便は、設定温度を確認した

**「荷捌き場に何も残っていない」と「画面の残りが0」の両方**を見るのが大事です。
どちらか片方だけだと、数え間違いが通ってしまいます。

## 3. 走行中

- 発進・停止・カーブは、**荷物があることを前提に**ゆるやかに。
  急ブレーキ1回で荷崩れします。
- 時間指定のある店舗を先に頭に入れておく。遅れそうなら**早めに連絡**。
  黙って遅れるのが一番信用を失います。
- **運転中はスマホを触らない。** チェックリストの操作は
  必ず停車してから。チェックは後からまとめて入れても問題ありません。
- 荷室の音が変わったら（ガタつき・ずれる音）、安全な場所に停めて確認する。

## 4. 荷降ろし（店舗ごと）

### 4-1. 到着したら、まず挨拶

**これは業務の一部です。** 品物と同じくらい大事です。

- 店舗に入るときは、必ず**先に声をかける**。
  「小島農園です。納品に伺いました。よろしくお願いします。」
- 通路を通るとき、お客様や店員さんとすれ違うときは
  「失礼します」「通ります」と声を出す。**無言で背後を通らない。**
- 検品してもらう相手の**名前と担当時間帯を覚える**。
  次回から名前で挨拶できると、こちらの融通も利きやすくなります。
- 他社の配送業者と鉢合わせしたら、**挨拶して順番を譲り合う**。
  搬入口は共用です。「お先にどうぞ」が言える人が結局早く終わります。
- 終わったら「ありがとうございました。失礼します。」まで言い切る。

急いでいるときこそ、挨拶だけは省かない。
省いた分の時間は稼げませんが、失った信用は取り返せません。

### 4-2. 降ろす手順

1. チェックリスト画面を**「荷降ろし」タブ**に切り替える。
   画面上部に**今降ろす店舗**が大きく出ています。
   これが積んだ順の逆＝手前から降ろす順です。
2. 扉を開ける。**開ける前に、扉際の荷物が落ちないか一瞬確認。**
3. 手前の荷物が、画面に出ている店舗のものか**ラベルで確認**する。
   違っていたら、積み間違いです。その場で画面の店舗一覧を見て、
   正しい順に降ろす（無理に順番を変えず、手前にあるものから処理する）。
4. **品目ごとに箱を数えながら**降ろす。
   画面の行と突き合わせて、合っていたらタップしてチェック。
5. 店舗の担当者に検品してもらう。**担当者の確認が取れるまで帰らない。**
6. 空コンテナ・返品があれば回収する（後述）。
7. 伝票を渡す／サインをもらう（店舗のルールに従う）。
8. その店舗の全行がチェックできたら「次の店舗へ」。
9. 荷室を閉め、施錠して次へ。

### 4-3. 数が合わない・傷んでいるとき

その場で勝手に判断しないこと。手順は決まっています。

1. **もう一度数える。** 数え間違いがいちばん多い原因です。
2. 荷室の他の場所に紛れていないか確認する（特に端数箱）。
3. それでも合わなければ、**店舗の担当者にその場で伝える。**
   後から連絡するより、目の前で共有したほうが必ず穏便に済みます。
4. **責任者へ連絡。** 伝える内容は決まっています:
   - 店舗名
   - 品目・規格
   - 伝票の数 / 実際の数
   - 傷みの場合は状態（写真を撮る）
5. 指示を待つ。自己判断で「他の店の分から回す」のは**絶対にしない**。
   その店の荷物が足りなくなるだけです。

**傷み・破損は写真を撮ってください。** 後の対応が全く変わります。

### 4-4. 空コンテナ・返品の回収

- 空コンテナは**店舗ごとに数えて**回収する。数えずに積むと合わなくなります。
- 汚れているコンテナは分けて積む（きれいなものと混ぜない）。
- 返品は**必ず品目・数・理由を記録**する。口頭だけで持ち帰らない。
- 空コンテナは、**残りの配送先の荷物を潰さない場所**に積む。
  通常は扉際・上段。奥に押し込むと次の店で荷物が出せなくなります。

## 5. 帰着後

- [ ] 荷室が空になっている（積み残しがない）
- [ ] 空コンテナを所定の場所に降ろした
- [ ] 返品・不足・破損を責任者に報告した（記録も残す）
- [ ] 伝票・サイン済み帳票を提出した
- [ ] チェックリスト画面の「荷降ろし」タブが**残り店舗 0** になっている
- [ ] 荷室を掃除した（土・葉くず・水）。次の便の品物が汚れます
- [ ] 車両の異常（音・警告灯・タイヤ）があれば報告した
- [ ] 燃料を規定どおりに入れた
- [ ] 施錠し、鍵を所定の場所に戻した

**気づいたことは、小さくても報告・記録してください。**
「この店は台車が使えない」「この時間は搬入口が混む」といった情報が、
次に入る人の時間を守ります。

## 6. チェックリスト画面の使い方

### 6-1. どこにあるか

1. システムにログインする
2. **受注一覧**を開く
3. その日の受注の**「確認」**を押す
4. チェックリスト画面が開く（URL: `/dashboard/orders/<受注ID>/checklist`）

スマホ前提の画面です。パソコンでも開けますが、現場ではスマホで使ってください。

### 6-2. 画面の見方

- **上のタブ**: 「積み込み」／「荷降ろし」を切り替える。
  順番は自動で逆になります。**自分で逆に読み替えないでください。**
- **大きい数字3つ**:
  - `対象店舗` … このモードで扱う店舗の総数
  - `完了` … 全品チェックが終わった店舗の数
  - `残り店舗` … あと何軒か
- **今の店舗**: いちばん大きく出ている店舗が、いま作業する店舗です。
  その下に品目ごとの箱数が並びます。**タップでチェック。**
- **「次の店舗へ」**: 今の店舗が終わったら押す。次の未完了店舗に進みます。
- **店舗一覧**: 全店舗の進み具合。**タップするとその店舗に飛べます**
  （順番を飛ばして先に処理したいときに使う）。
- **「品目ごとの合計」**（積み込みタブのみ）: 積む前の総数確認用。
  品目・規格ごとの箱数と、その品目が行く店舗名が出ます。チェックはできません
  （数えるためだけの表示です）。
- **「チェックを全部外す」**: やり直したいとき。
  今表示しているモードだけが対象で、もう一方には影響しません。

### 6-3. 知っておくこと

- **チェックは共有されます。** 2人で作業していれば、
  相手が入れたチェックも自分の画面に出ます。
  ただし**同じ箱を2人で数えないよう、店舗単位で分担**してください。
- **チェックは1週間で自動的に消えます。** それ以降は使わないので問題ありません。
  逆に言えば、**記録として残るものではありません。**
  正式な記録は紙の帳票と伝票です。
- **圏外でチェックが入らないことがあります。**
  「保存できませんでした」と出たら、電波が戻ってからもう一度タップしてください。
  **画面が信用できないときは、紙の一覧表を正とします。**
- 紙とスマホが食い違ったら、**紙と実物を数え直す**のが正解です。

---

## 7. 迷ったときの判断基準

| 状況 | どうするか |
|---|---|
| 総数が合わない | **積まない。** 先に原因を確認する |
| 積む順が分からない | アプリの「積み込み」タブの順。紙の一覧表の店舗順と同じ |
| 降ろす順が分からない | アプリの「荷降ろし」タブの順（積んだ順の逆） |
| 積み間違えた | 気づいた時点で積み直す。店の前で直すほうが高くつく |
| 荷物が足りない | その場で店舗に伝え、責任者に連絡。他店の分を回すのは禁止 |
| 傷んでいる | 写真を撮る。店舗に伝える。責任者に連絡 |
| 遅れそう | **早めに連絡。** 遅れてから連絡しない |
| アプリが動かない | 紙で進める。作業を止めない。後で報告 |
| 判断に迷う | **責任者に聞く。** 勝手に決めないほうが必ず安く済む |

### 現場で確認して埋めてほしい項目

実際のやり方と違うところは、現場に合わせて上書きしてください。

- 鍵・車両の管理方法
- 事故・車両トラブル時の連絡順序
